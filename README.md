# Классификатор изображений кошек и собак
## О проекте
Это первый учебный проект после цикла видеоуроков от selfedu по нейросетям.
Его функция заключается в распознавании, изображение какого питомца (кот или собака)
было подано нейросети.

Этот проект имеет для меня принципиальное значение и выступает показателем того,
что первые шаги в нейронных сетях сделаны успешно.

## Техническая сторона
Нейросеть реализована с помощью фреймворка PyTorch и предобученной сети ResNet50,
последний слой которой был заменен и обучен под задачу различать котов и собак.
